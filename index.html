ABOUT

About Palette Lab 3.0

Built as a local, static web app. Works without a website or account, and the same files can later be hosted on a website. Everything is stored on this device in browser storage. Export your backup to move between devices.

The Liquitex Japan BASICS page lists 80 colours. The May 2026 Regular Type chart lists 122 entries, although the Japanese distributor advertises 119 saleable colours. Palette Lab includes all 122 chart entries so none are silently omitted; availability must be checked before purchase.

Digital HEX starting values are illustrative estimates, not manufacturer-measured spectral or calibrated swatch data. Results are starting points, not guaranteed mixing instructions. Metallic, fluorescent and iridescent finishes cannot be faithfully modelled by RGB values.

The Mixbox mixing engine is loaded automatically from a local copy (mixbox.js) when available, otherwise from the official author website (requires internet). For fully offline mixing, run the included one-time Windows installer to save a local copy. If loading fails, the app uses its simpler RYB approximation.
